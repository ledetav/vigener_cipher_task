# 🔐 Vigenère Cipher

Реализация шифра Виженера на Python с юнит-тестами.

## 📚 Описание

Шифр Виженера — это полиалфавитный шифр, при котором каждая буква открытого текста смещается на определённое количество позиций, зависящее от соответствующей буквы ключа.

Особенности:
- Поддержка латинского алфавита (регистр не влияет).
- Шифруются только буквы, все остальные символы сохраняются.
- Юнит-тесты охватывают реальные сценарии и крайние случаи.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ledetav/vigenere_cipher_task.git
cd vigenere_cipher_task
```
2. (Опционально) создайте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
```
3. Установите зависимости (если есть):

```bash
pip install -r requirements.txt
```

4. Запустите пример:

```bash
python main.py
```
